# 🎯 GDG Al-Azhar — Find Someone Who...

An interactive **Networking Activity** created for the GDG on Campus Al-Azhar closing event.

Participants race against the clock to find people who match **12 fun challenges**, write their names, and complete the board.

### ✨ Features

* ⏱️ Live timer
* 🎯 Score & progress tracking
* 🧩 12 networking challenges
* ✍️ Name input for each challenge
* 🔊 Completion sound
* 🎉 Final results screen
* 📱 Responsive design

### 🛠️ Built With

HTML • CSS • JavaScript

**GDG on Campus Al-Azhar — Closing & Networking Activity**
